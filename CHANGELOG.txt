## v0.1.0 (2026-05-11) - First public release

The first version of Vamoose's Field Notes on CurseForge. This release
covers the full capture-and-replay loop: paste coordinates from anywhere,
get clickable waypoints on your map, and curate them into reusable
libraries.

### Capture

Open the window with `/vfn` and paste any text that contains coordinates.
The parser handles:

- `/way 42.1 56.8 Spot name` (naked decimals)
- `/way Harandar 42.1 56.8 Spot name` (named zones; alias DB covers every
  Blizzard zone + city + dungeon)
- `/way #2480 42.1 56.8 Spot name` (numeric mapID)
- Multi-line Wowhead block paste -- each coord line inherits the nearest
  "Zone Name:" header above it
- Chat-link map pins (`|Hworldmap:...|h`) -- paste the link straight in
- Naked `42.1, 56.8` -- falls back to your current zone

Hit **Send Waypoints** to ship the parsed list to your waypoint backend.
**Pin Here** is a one-click commit of your current player location as a
single-entry field note (independent of the paste box).

### Waypoint backends

- **TomTom** -- preferred. Multi-pin, per-coord arrow.
- **Blizzard** -- fallback (`C_Map.SetUserWaypoint`). Only the first
  entry of a multi-coord set is sent (one super-tracked waypoint at a
  time is a game limitation). World-map pins for the open card still
  paint for the whole set regardless of backend.

### The Library

Three-column workspace:

- **Libraries** -- your collections. Default library auto-collects every
  capture; right-click any library for Rename / Delete (Default is
  protected). `+ New library` button creates additional collections.
- **Finder** -- cards in the active library. Search box (title / note /
  zone / source all searchable), filter chips
  (All / Ready / Has Note / Blocked), sort cycle (Recent / A-Z / Largest).
  Action row: Send Waypoints (whole card) / Move to.../ Delete. Card
  right-click also offers Move to.
- **Curator** -- the selected card. Stat cards on top
  (COORDS / MAP / STATUS), editable title + note (Save / Restore actions),
  read-only coord-preview list. Click any single coord to send a one-shot
  waypoint, or use **Copy coords** to open a multi-line copy dialog
  (one `/way` line per entry).

Status chips on each card: **ready**, **blocked**, **note**, **source**,
**default**.

### Stream history

The stream rail's history list has a library dropdown above it so you can
flip between which library's recent captures you're scrolling through
without leaving capture mode.

### Pre-loaded: Decor Vendors

Ships with a curated **Decor Vendors** library -- 92 zones, 216 vendor
coordinates -- generated from the Housing Decor Guide vendor DB. Use it
to fast-route decor shopping trips. The seeder is idempotent and
re-runnable via `/vfn seed`. Each zone-name card spans sub-maps where
applicable (Boralus parent + harbor inset, Harandar parent + Founder's
Point sub-zone, etc.) with per-vendor mapIDs so individual waypoints
route correctly.

### Other

- Minimap button (toggle with `/vfn minimap`) + addon compartment icon
- World-map pins for the currently-open field note's coords
- Account-scoped SavedVariables (all characters share the same libraries)
- Combat-safe: send operations bail out cleanly during combat lockdown
